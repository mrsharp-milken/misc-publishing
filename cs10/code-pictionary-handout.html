Code Pictionary

How to Play

1
Draw a picture on the left half of your paper (max 6 shapes), then pass to the next person
2
Write code on the right half that would recreate the drawing
3
Same person: Fold the paper to hide the drawing, then pass to the next person (only code is visible!)
4
New person, new paper: Read the code and draw what it describes on a fresh piece of paper (no peeking at original!)
5+
Continue for 6 rounds total, then reveal and compare the full chain from start to finish!

Shape Functions Cheat Sheet

Function Description Example
draw_rect(x, y, w, h, color) Rectangle with top-left corner at (x, y) draw_rect(2, 3, 4, 2, "red")
draw_circle(x, y, r, color) Circle centered at (x, y) with radius r draw_circle(5, 5, 2, "blue")
draw_ellipse(x, y, w, h, color) Ellipse centered at (x, y) draw_ellipse(5, 7, 3, 1, "green")
draw_arc(x, y, r, start, end, color) Arc centered at (x, y). Angles: 0=right, 90=up draw_arc(5, 5, 2, 0, 180, "orange")
