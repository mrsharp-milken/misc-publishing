# Function Stencils Summary

## Quick Summary
A hands-on activity that teaches function parameters through stencil-based design. Students create blueprints using 10+ shapes, then work in pairs to color each blueprint with assigned stencils. Key learning: functions like `draw_shape()` need parameters for shape type, position, size, rotation, and color.

---

## Detailed Summary

## Overview
This is an educational presentation about function parameters using a hands-on stencil-based activity. The lesson teaches students about how functions can be customized with different parameters through a creative collaborative exercise.

## Key Topics

### Do Now Activity
Students are asked to think about what parameters a `draw_shape()` function should have.

### Proposed Function Parameters
The lesson identifies five essential parameters for a shape drawing function:
- **Type/name of shape** - What shape to draw (e.g., Moon, Wave, Oval)
- **Position** - Where to place the shape (center coordinates)
- **Size** - How large to draw it (Big or Small variants)
- **Rotation** - The angle at which to rotate the shape
- **Color** - The color to fill the shape with

### Available Shapes
The stencils include the following shapes:
- **Primary shapes**: Oval, Wave, Triangle, Post, Moon
- **Alternative shapes**: Almond, Slice, Bean, Blob, L

### Activity Components

#### Part 1: Blueprint Creation (5 minutes)
Students create their own design blueprint with the following constraints:
- Use 6 or more unique shapes
- Use 10 or more total shapes
- Include both big and small versions of shapes
- Suggested themes:
  - Graffiti art
  - City skyline
  - Garden/plants
  - Abstract portrait

#### Part 2: Stencil Selection
Students select a physical stencil and color for their assigned shape.

#### Part 3: Rotate and Color (15 minutes)
Working in pairs, students execute the coloring task:
1. Partner with someone who has the big/small version of your assigned shape
2. Rotate through all completed blueprints as a pair
3. At each blueprint, locate instances of your assigned shape (labeled as "Big ___" or "Little ___")
4. Use your stencil to color in every location where your shape appears
5. Move to the next blueprint once complete
6. Continue rotating until all blueprints have been visited

#### Part 4: Debrief
A final discussion about the purpose and learning outcomes of the activity.

## Learning Objectives
This lesson appears to teach:
