CSS Selector Practice

Complete these 5 challenges to practice tag, class, and ID selectors. Copy the HTML and CSS into your editor and fill in the blanks!

1Tag Selectors

Use tag selectors to style HTML elements. Make the h1 blue and the paragraph red.

HTML (index.html) CSS (style.css) 
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title></title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>Hello World!</h1>
    <p>I am learning CSS!</p>
  </body>
</html>
 
___ {
  color: blue;
}

p {
  color: ___;
}
Your result should look like this:

Hello World!

I am learning CSS!
